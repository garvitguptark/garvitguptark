### What I'm building

**[Rootwise](https://github.com/garvitguptark/rootwise)**: AI diagnostic tutor · [live](https://rootwise-six.vercel.app)  
Finds the root cause of a student's learning gap instead of just marking answers wrong. The diagnosis runs on Bayesian inference over a prerequisite graph and picks each question by expected information gain. On 2,000 simulated students it gets the exact gap right 82% of the time in about 14 questions, against 54–63% for a 36-question fixed test. An LLM Socratic tutor then teaches the missing concept, in 7 Indian languages.

**Smart Medication Dispenser**: STM32 Blue Pill + ESP32  
Hardware that handles medicine dispensing, paired with a web dashboard for health checks and caretaker alerts.

**Digital Twin Predictive Maintenance**: team project  
STM32-based health monitoring for electric motors, feeding a digital twin to catch problems before they become failures, with a kill-switch mechanism for safety.

**[frontend-flow](https://github.com/garvitguptark/frontend-flow)**: open-source Claude Code plugin  
Splits frontend design work across subagents and routes the simpler steps to a cheaper model tier, so you spend fewer tokens getting a good UI.

**Last Candle**: multiplayer Roblox horror game · [@lastc.andle](https://www.instagram.com/lastc.andle)  
Light five soul candles in a haunted manor, hide from the Hollow Bride, and make it out the front door. Built in Roblox Studio.
